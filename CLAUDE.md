# LeadFactory

Lire `AGENTS.md`, puis `docs/AGENT-START.md` avant une mission. Le contexte personnel de cette installation est dans `.leadfactory/` lorsqu'il a été créé par `npm run factory`.

Les méthodes incluses sont dans `full-app/resources/agency-kit/`. Utiliser les API documentées dans `docs/AGENT-API.md` pour le travail métier et préserver les données locales.
